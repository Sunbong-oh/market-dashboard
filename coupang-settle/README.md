# 쿠팡 부모님댁 배송 월별 정산

쿠팡 계정 하나를 부모님과 같이 쓰고 결제는 내가 할 때, **부모님댁 주소로 배송된 주문의 결제액을 월별로 합산**해 주는 브라우저 스크립트입니다.

- 로그인된 내 브라우저에서 동작하므로 비밀번호를 어디에도 저장하지 않습니다.
- 주문목록 페이지의 주문마다 상세페이지를 열어 배송지·결제금액·환불금액·주문일을 읽습니다.
- 배송지에 **부모님댁 주소 키워드**가 있으면 부모님 몫으로 분류합니다.
- 월별 합계(환불 차감), CSV 내보내기, 카톡용 정산 메시지 복사를 지원합니다.
- 수집 결과와 직접 고친 값은 브라우저(localStorage)에 저장되어 다음 달엔 새 주문만 추가로 조회합니다.

## 설치 (1회)

1. PC 크롬/엣지에 [Tampermonkey](https://www.tampermonkey.net/) 확장 프로그램을 설치합니다.
   - 크롬은 확장 프로그램 관리 화면에서 **개발자 모드**를 켜야 사용자 스크립트가 동작합니다.
2. Tampermonkey 아이콘 → **새 스크립트 만들기** → 기본 내용을 지우고 `coupang_settle.user.js` 내용 전체를 붙여넣고 저장합니다.

> Tampermonkey 없이 한 번만 써보려면: 쿠팡 주문목록 페이지에서 F12 → Console 탭에 파일 내용을 붙여넣고 Enter.

## 매달 사용법

1. 쿠팡 로그인 → **마이쿠팡 > 주문목록** 으로 이동합니다.
2. 오른쪽 아래 **💰 쿠팡 정산** 버튼을 누릅니다.
3. (처음 한 번) **설정**에 주소 키워드를 입력합니다.
   - 부모님댁: 아파트명, 도로명+번지 등 그 주소에만 있는 단어. 예) `행복아파트, 행복로 12`
   - 내 집: 같은 방식. 예) `푸른빌라`
   - 이름은 '주문자' 칸에도 나오므로 키워드로 쓰지 마세요. 띄어쓰기는 무시하고 비교합니다.
4. **이 페이지 주문 수집**을 누릅니다. 주문목록 다음 페이지로 넘어가서 다시 누르면 누적됩니다.
5. 월별 합계 표에서 해당 월의 **정산 메시지 복사** → 카톡에 붙여넣기.

정산 메시지 예시:

```
[쿠팡 정산] 2026년 9월 부모님댁 배송분
- 9/15 25,500원 (환불 5,000원 차감)
- 9/20 9,000원
합계: 34,500원 (2건)
```

## 확인/수정

- 키워드가 양쪽 다 있거나 둘 다 없으면 **확인필요**(빨간 줄)로 표시되고 합계에서 빠집니다. 분류를 직접 선택하세요.
- 결제액·환불·주문일이 틀리면 표에서 직접 고칠 수 있고, 다시 수집해도 고친 값이 유지됩니다.
- ❌ 표시는 상세페이지 조회 실패입니다. 다시 **수집**을 누르면 실패한 주문만 재시도합니다.
- 키워드를 바꿨다면 **저장 후 전체 다시 분류**를 누르세요(모든 주문 상세를 다시 조회).
- 월 구분은 **주문일 기준**입니다.

## 쿠팡 화면이 바뀌어서 안 될 때

쿠팡 HTML 구조에 의존하지 않도록 화면 텍스트(`총 결제금액 ○○원`, `주문일자`, `배송지` 등)를 정규식으로 읽습니다.
그래도 금액/날짜를 못 읽으면 `parseAmount` / `parseDate` / `parseAddressSnippet` 정규식을 조정하면 됩니다.
주문 상세페이지 주소 형식이 다르면 스크립트 상단 `DEFAULT_CONFIG.detailUrl`(기본 `https://mc.coupang.com/ssr/desktop/order/{id}`)을 바꾸세요
(주문목록에 상세 링크가 있으면 그 링크를 우선 사용).

파싱 로직 테스트: `node coupang-settle/test_parse.js`
