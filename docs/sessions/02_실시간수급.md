# 02 실시간 수급체크 (장중·장마감, 회사 PC 실행기)

## 범위
- 홈의 🔴 실시간 칸: 시장지수·원/달러·국고채, 투자자별 수급(외국인·기관·개인, 현물·선물), 테마, 거래대금 상위, 이슈 종목, 주요 뉴스. 장마감 리포트(15:30 이후).
- 저장소 `Sunbong-oh/kb-market-report` 가 본체. 홈(market-dashboard)은 flow-live 브랜치 데이터를 덧씌워 보여 준다(`LIVE_CLOSE_JS`).

## 핵심 파일·작업 (kb-market-report)
- `live_snapshot.py`: 장중 루프(START 08:00). `free_port`(8000 정리), `clear_stale_intraday`(개장 전·전일 381점 지움, 네이버 분봉으로 채움), `clear_stale_bond`(국고채 전일 값은 비움), `fallback_market`(KB 안 될 때 네이버·다음).
- `market_issues.py`: 이슈 종목(구글 뉴스 다중 검색, `PIN_STOCKS`, `GOSSIP`, `_has_word`).
- `tls_trust.py`: 회사 PC 인증서 문제 해결. `report.py`: 장마감 리포트(flow-live 기반, 실패 시 KB 서버 방식).
- 워크플로: `live-snapshot.yml`(PC `[self-hosted, windows]`, shell cmd), `close-report.yml`(GitHub 서버, KB 직접 접속 안 함), `kb-pc-probe.yml`·`pc-net-probe.yml`(진단), `oi-history.yml`.
- flow-live 브랜치: snapshot.json, map.json, issues.json, prices.json.
- 데이터 출처 메모: 선물·지수 분봉 = KB, 현물 투자자 장중 = 다음 `finance.daum.net/api/investor/{KOSPI|KOSDAQ}/times`(Referer 필요), 지수 분봉 폴백 = 네이버. 개장 전 KB 투자자 값은 0.
- 실행기 ①이 이 작업을 점유한다(08:10~16:05). 다른 KB 작업은 ②가 맡는다.

## 네이버 기준 수급 · 글로벌 지수 (KB 비교용, 2026-11-12 시작)
- kb-market-report `naver_flow.py` + `naver-flow.yml`(GitHub 서버 ubuntu, KB·회사 PC 안 씀): 평일 08:30~17:20 1분마다(이어달리기), 밤 매시간 1번(미국 지수) → `naver-live/naver.json`.
- 네이버 자료: m.stock.naver.com `/api/index/{KOSPI|KOSDAQ|FUT}/integration`(개인·외국인·기관계·프로그램), api.stock.naver.com 분봉, polling worldstock(미국·일본·중국·홍콩·대만 11개 지수).
  금융투자·옵션 투자자별은 네이버에 없음. 외국인 누적 분 단위 흐름은 이 작업이 1분마다 쌓은 것(꺼진 시간은 빈칸).
- 화면: **별도 페이지 https://sunbong-oh.github.io/market-dashboard/naver/** (market-dashboard `naver_live.py` `build()`). 홈·메뉴에는 넣지 않는다(사용자 지시 2026-11-12 '홈은 그대로, 따로 만들어 비교'). 내용: 네이버 기준 수급 + 'KB vs 네이버 비교' 표 + '🌏 글로벌 지수'. 교차차트는 같은 `FUT_JS`(d.note 로 아래 설명만 바꿈).
