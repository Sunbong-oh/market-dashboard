# 08 저점신호 (/bottom/)

## 범위
- 폭락장에서 지수 저점(바닥)이 나오는 순간을 점검하는 칸. 홈 칸 **📉 저점신호기**(첫 줄 이름·자세히, 다음 줄 판정과 수치, 큰 글씨, `order:-2` 로 실적속보 제목보다 위). **홈 칸은 풋콜 5일 평균 0.9 이상일 때만 보인다**(`HOME_PC_MIN`, 사용자 지시 2026-11-23. 다이버전스 신호가 켜져도 0.9 미만이면 숨김 — 사용자가 선택. 메뉴·페이지는 항상) + `/bottom/` 페이지. 2026-11-22 시작.
- 판정은 '예측'이 아니라 점검표다. 표현은 **'바닥 가능성'**(사용자 지시 2026-11-22, '바닥 후보'라고 쓰지 않는다).

## 판정 (bottom_page.py `LV`)
| 상태 | 조건 |
|---|---|
| 🟢 투매형 바닥 가능성 | 풋콜(Cboe 주식+ETP, CNN 근사) 5일 평균 1.0 이상 → VIX 종가가 장중 고점에서 15% 이상 꺾임, 자금시장 정상 |
| 🟢 다이버전스 바닥 가능성 | 1차 폭락 저점을 종가로 깨는데 VIX 장중 고점과 풋콜 5일 평균 고점이 1차 때보다 낮음, 자금시장 정상 |
| 🔴 바닥 신호 무효 (자금시장 경색) | 위 신호가 나왔지만 금융CP−T-bill 5일 평균 1.0%p 이상(2008년 3·7·11월은 모두 중간 저점이었음) |
| 🔴 바닥 신호 무효 (외국인 하방 옵션 우세) | 위 신호가 나왔지만 외국인 코스피200 옵션 하방(콜 매도+풋 매수)이 상방(콜 매수+풋 매도)의 2배↑이고 하방이 50억↑(콜 매도 20억·풋 매도 10억 같은 작은 규모는 의미 없음, 사용자 2026-11-23)(사용자 경험칙 2026-11-23, 기준값은 가정 `KR_BEAR_RATIO`·`KR_BEAR_MIN`). 숫자는 KB증권 모바일 웹 투자자별매매동향(m.kbsec.com, 앱 '시장동향 > 투자자동향'과 같은 값)을 먼저 쓰고, 안 되면 flow-live snapshot.json·장 마감 기록(Open API IVSA0070). 2026-11-23 확인: 앱·웹 요약 콜 −97억인데 Open API·웹 상세는 −25억(위클리 포함 차이로 보임, 확인 필요). 지난 날짜는 Open API 값이라 작게 나온다. 표지·홈 판정에 모두 적용 |
| 🟠 공포 확산 중 | 1차 저점을 깨면서 VIX·풋콜도 더 높아짐 |
| 🟡 바닥 확인 중 | 1차 폭락 뒤 아직 저점을 다시 깨지 않음 |

- 1차 폭락 저점(비교 기준)은 자동: 최근 5거래일을 뺀 직전 60거래일의 최저 종가(`bottom_signals.compute`).
- 국내 보조 신호(사용자 경험칙): **외국인 코스피200 풋옵션 하루 순매도 200억원 이상**이 나오기 시작하면 바닥 준비 가능성. 데이터는 kb-market-report 장마감 기록(`archive/날짜/본문_장마감수급.txt`의 풋옵션 줄, KB증권 Open API, 2026-10-01부터)을 GitHub 공개 주소로 읽는다. 장기 검증은 아직 안 됨(KRX 일별 자료를 HTS에서 받아 주면 검증).
- 자금시장 필터 근거: 성공 바닥 2009.3(0.42)·2011(0.18~0.25)·2022.10(0.16)·2025.4(0.10) vs 실패 2008.3(1.43)·2008.7(1.15)·2008.11(1.64). 예외 2020.3.23(1.12, 연준 무제한 유동성).

## 화면 (2026-11-23 사용자 지시)
- 판정 5단계를 모두 보여 주고 지금 판정만 색깔+깜빡임, 나머지는 회색(`ladder()`, 홈은 이름표 칩). '신호 있음'은 '바닥 신호 무효 (자금시장 경색)'으로 바꿈.
- '지금 상황' 상자(`situation()`·`summary()`): 1차 저점 대비 위치·겁(VIX·풋콜)이 커졌는지·풋콜 1.0까지 거리·자금시장·정리(다음에 볼 것)를 숫자로 자동 작성. 홈 칸에도 한 줄(`home_line()`).
- '바닥 확인 중' = 1차 저점을 아직 다시 깨지 않은 상태(바닥 확인도, 바닥 아님도 아님). 옛 이름 '재시험 대기'(사용자 지시 2026-11-23으로 바꿈).
- 신저점에서 종가가 2% 넘게 반등하면 '공포 확산 중'을 끝내고 '바닥 확인 중'(`REBOUND`, 가정, 사용자 2026-11-23 '나스닥 선물 2% 반등 중인데 공포 확산 표현이 안 맞아'). 판정은 마지막 미국장 마감 기준이라 표지·홈에 '○○ 미국장 마감 기준'을 붙이고, 지금 S&P500·나스닥 선물(Yahoo ES=F·NQ=F, 사이트 만들 때)을 같이 보여 준다. 선물대로 끝나면 판정이 바뀌는 경우 한마디(`flip_hint`).

## 코스피 PBR (저점 근접, 2026-11-23 사용자 지시)
- 기준 **코스피 PBR 0.8배 이하 = 저점 근접**(`PBR_NEAR`). 표지 KEY DATA·지금 상황·코스피 점검표 ⑥줄·홈 칸에 지금 값과 '0.8배가 되는 코스피 수준'을 표시. 판정 단계는 바꾸지 않는 별도 표시.
- KRX 공표값은 해외 서버에서 못 받아(data.krx.co.kr 403) 직접 계산: 시가총액(kb flow-live map.json, 코스피 보통주) ÷ 자본총계(study-fin DART 최근 정기보고서 eq) × 보정계수 `PBR_CAL`(0.949 = 11/20 KRX 1.20 ÷ 우리 1.265). 11/23 10:40 약 1.16배, 0.8배 = 코스피 약 3,240.
- 할 일: 가끔 KRX 공표값(인덱서고 KOSPI PBR, 출처 한국거래소)과 비교해 `PBR_CAL` 을 고친다.
