# 08 저점신호 (/bottom/)

## 범위
- 폭락장에서 지수 저점(바닥)이 나오는 순간을 점검하는 칸. 홈 칸 **📉 저점신호기**(첫 줄 이름·자세히, 다음 줄 판정과 수치, 큰 글씨, `order:-2` 로 실적속보 제목보다 위) + `/bottom/` 페이지. 2026-11-22 시작.
- 판정은 '예측'이 아니라 점검표다. 표현은 **'바닥 가능성'**(사용자 지시 2026-11-22, '바닥 후보'라고 쓰지 않는다).

## 판정 (bottom_page.py `LV`)
| 상태 | 조건 |
|---|---|
| 🟢 투매형 바닥 가능성 | 풋콜(Cboe 주식+ETP, CNN 근사) 5일 평균 1.0 이상 → VIX 종가가 장중 고점에서 15% 이상 꺾임, 자금시장 정상 |
| 🟢 다이버전스 바닥 가능성 | 1차 폭락 저점을 종가로 깨는데 VIX 장중 고점과 풋콜 5일 평균 고점이 1차 때보다 낮음, 자금시장 정상 |
| 🔴 신호 있음, 자금시장 경색 | 위 신호가 나왔지만 금융CP−T-bill 5일 평균 1.0%p 이상(2008년 3·7·11월은 모두 중간 저점이었음) |
| 🟠 공포 확산 중 | 1차 저점을 깨면서 VIX·풋콜도 더 높아짐 |
| 🟡 재시험 대기 | 1차 폭락 뒤 아직 저점을 다시 깨지 않음 |

- 1차 폭락 저점(비교 기준)은 자동: 최근 5거래일을 뺀 직전 60거래일의 최저 종가(`bottom_signals.compute`).
- 국내 보조 신호(사용자 경험칙): **외국인 코스피200 풋옵션 하루 순매도 200억원 이상**이 나오기 시작하면 바닥 준비 가능성. 데이터는 kb-market-report 장마감 기록(`archive/날짜/본문_장마감수급.txt`의 풋옵션 줄, KB증권 Open API, 2026-10-01부터)을 GitHub 공개 주소로 읽는다. 장기 검증은 아직 안 됨(KRX 일별 자료를 HTS에서 받아 주면 검증).
- 자금시장 필터 근거: 성공 바닥 2009.3(0.42)·2011(0.18~0.25)·2022.10(0.16)·2025.4(0.10) vs 실패 2008.3(1.43)·2008.7(1.15)·2008.11(1.64). 예외 2020.3.23(1.12, 연준 무제한 유동성).

## 핵심 파일·작업
- `bottom_page.py`: 페이지·홈 줄·`build()`. `PUBLIC=False` + `build_site.py` MENU 에서 `("bottom/", "저점신호")` 빼면 숨김.
- `bottom_signals.py`: 계산(Cboe 풋콜, Yahoo ^GSPC·^KS11·^VIX, FRED 금융CP·T-bill·하이일드·Baa). **`.claude/skills/market-bottom-signals/scripts/bottom_signals.py` 와 같은 파일**이다. 고치면 두 곳(그리고 kb-market-report `.claude/skills/...`)을 같이 고친다.
- 스킬: `.claude/skills/market-bottom-signals/`(이 저장소를 여는 어느 계정이든 Claude Code가 자동으로 불러온다). 사례표는 `references/historical_cases.md`.
- site.yml 이 사이트를 만들 때마다 다시 계산(약 15초, Cboe 일일 JSON 약 100개). 결과 `_site/bottom/state.json`.
- 확인: `python -c "import build_site as b, bottom_page; from pathlib import Path; p=Path('_site'); p.mkdir(exist_ok=True); print(bottom_page.build(p, b.page) is not None)"`
