# 05 전일 강세종목 (/strong/)

## 범위
- 글로벌(미국·한국·중국 등) 전일 강세종목 리포트 작성·등록. 규칙의 전부는 CLAUDE.md '전일 강세종목 리포트' 절 — **반드시 먼저 읽기**.

## 핵심 요약 (CLAUDE.md 와 다르면 CLAUDE.md 가 우선)
- **종가 기준 +5% 이상일 때만 올린다**(사용자 지시 2026-11-12). 미만이면 올리지 않고 알린다.
- 파일 `us_strong/YYYY-MM-DD_TICKER.html` + `us_strong/index.json` 한 줄(date, ticker, exchange, name, nameEn, sector, price, changePct, priceNote, headline, tags, file, market{...}, pod, 한국은 `posted`).
- 강세 근거를 앞세우고 '폭락 뒤 반등' 표현 금지. 장전 급등은 분석만 해 두고 종가로 고쳐 다음 날 등록.
- 내리는 시각: 아시아(일본·중국·홍콩)=등록일 09:00, **한국 = 15:30 이후 올림 → 다음 평일 09:00에 내림**(사용자 지시 2026-11-11, `kr_until`·`strong_gone`), 미국 = 등록일 17:00 뒤 해외주식 리포트 아래로, 22:30 지나면 홈에서 뺌. /strong/ 목록엔 남는다.
- `pod`: 출근길(07:00 전 merge) 음성에 읽힘, 한국 종목은 퇴근길 장마감 브리핑(15:58 전 merge)에도 읽힘. 기호·영문 약어를 풀어 쓰고 위스퍼 넘버 금지.
- 확인: `python -c "import build_site as b; b.build_strong()"`, 휴대폰 390px 가로 스크롤 없음.
- PC 동기화: 등록분은 `전일 강세종목\날짜_종목명.html/.pdf` 로 자동 내려받기.
