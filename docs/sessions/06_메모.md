# 06 Brian's memo (/memo/)

## 범위
- 종목 리포트가 아닌 시장 점검·생각거리 글, 내려받기 파일, 🎧 생각정리 팟캐스트.

## 핵심 요약 (CLAUDE.md 'Brian's memo' 절 참조)
- 파일 `memo/<YYYY-MM-DD>_<짧은영문>.html`(+ .ppt·.pdf) + `memo/index.json` 한 줄(date, title, sub, headline, tags, file, downloads[[버튼 이름, 파일]]). 코드 `build_site.py` `build_memo()`/`memo_card`.
- site.yml 자동 실행 경로에 memo/ 가 없어 **메모만 바꾼 커밋은 `trigger-site/` 에 파일 하나를 같이 넣어야** 사이트가 다시 만들어진다(해당 폴더는 원래 루틴 전용이지만 이 용도는 규칙에 허용됨).
- 팟캐스트: memo/ 가 main 에 올라오면 `memo-podcast.yml` → `memo_pod.py` 가 음성을 만들어 `memo-podcast` 브랜치 피드로 올림. 표·그림 제목·출처 줄은 읽지 않음. 구독 https://raw.githubusercontent.com/Sunbong-oh/market-dashboard/memo-podcast/feed.xml
- 스타일은 KB 스타일(CLAUDE.md 리서치 스타일). 첫 글: 2026-10-27 "한국만 약한가, 메모리가 약한가"(빌더 `/mnt/project-files/kr-weak/`, 환경에 없을 수 있음).
